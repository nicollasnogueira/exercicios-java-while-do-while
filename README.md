# Exercícios Java - while e do while

Atividade de Programação de Soluções Computacionais — primeiro semestre.

Este repositório contém os 9 exercícios da lista sobre estruturas de repetição, organizados em arquivos separados (`Exercicio01.java` até `Exercicio09.java`).

Para executar um exercício usando o terminal:

```bash
javac Exercicio01.java
java Exercicio01
```

Cada arquivo pode ser compilado e executado individualmente.
